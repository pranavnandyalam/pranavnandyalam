# Hi, I'm Pranav 👋

Engineering student at the University of Michigan. I build at the intersection of **reinforcement learning, robotics and autonomous AI agents**, and I care about measuring things honestly: held-out seeds, confidence intervals, pre-registered experiments, and safety limits that don't depend on the AI behaving.

## What I'm building

- **[Topple](https://github.com/pranavnandyalam/topple)**: CI for robots. A self-balancing robot in MuJoCo where a CPU-trained PPO policy (Stable-Baselines3, exported to ONNX) beats PID and LQR baselines across 200 held-out seeds. Now working on waypoint navigation under push disturbances.
- **[Autonomous Research Lab](https://github.com/pranavnandyalam/autonomous-research-lab)**: a team of Claude Code agents that scouts AI research, runs CPU-scale experiments, reviews its own work and writes papers, inside a Docker Sandboxes microVM with deny-all networking and a non-AI supervisor.
- **[Agent Lab results](https://github.com/pranavnandyalam/agent-lab-results)**: what that lab has produced so far: pre-registered experiments on small LLMs (judge criterion reversal, CoT monitoring, quantization and reasoning loops). AI-written and not peer reviewed, with every claim tracked.
- **[Red Queen](https://github.com/pranavnandyalam/red-queen)**: attacker and defender LLM agents harden a web app's source code; a referee keeps a patch only if live exploits stop working and the app still passes health checks. Built in Jac at JacHacks 2026.
- **[Claude-supervised portfolio](https://github.com/pranavnandyalam/claude-portfolio)**: a deterministic Python engine trades three published ETF strategies on a paper account while scheduled Claude Code sessions supervise within hard risk limits.
- **[Jarvis](https://github.com/pranavnandyalam/jarvis)**: a personal agent on the Claude Agent SDK with custom MCP servers for calendar, macOS automation, web research and a local knowledge base.

Earlier: [Parkinson's detection from DaTscan images](https://github.com/pranavnandyalam/park-model) · [gesture-controlled audio with MediaPipe](https://github.com/pranavnandyalam/song-tune-computer-vision) · [audio embeddings for music similarity](https://github.com/pranavnandyalam/music_embed)
